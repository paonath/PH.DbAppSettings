**Area**: `frontend`
**Source**: `source-tour-booking.md` lines 29–37

## Prompt for spec-generator

Create a specification for the Angular 19 SPA of a Tour Booking Portal. Pages: /tours (tour list with search and date/price filters), /tours/:id (tour detail with inline booking form), /my-bookings (authenticated user's booking history), /admin/bookings (admin-only table using AG Grid). The booking form must validate seat count and show availability. The admin table must support filtering and sorting. Use Angular standalone components and route guards for authenticated and admin routes.
